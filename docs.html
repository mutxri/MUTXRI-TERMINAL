MX TERMINAL
Documentation / Command reference

Command reference

The shell takes a ticker, a panel name, or both together. Type a command and press Enter. Everything below is a command the terminal actually accepts.

Getting started

TICKER
A ticker on its own
Open a security
Type a ticker to load that security, for example SCOM. Add a panel name to open both, for example MTN FINANCIALS.

Panels

HEATMAP
HEATMAP
The board at a glance
Every security as one cell, grouped by sector. A cell carries its ticker, so the board reads without a lookup. Green for a rise, red for a fall, a neutral tone where a security closed unchanged, and a dash where no change was published.
SCREENER
SCREENER EQS
Filter the listed universe
Screen the securities on the selected exchange by price, change, volume and the derived ratios.
TRADE
TRADE TR
The paper book
Place simulated buys, sells and shorts at real exchange prices. Orders are accepted only while the exchange is in session, and the book is stored in this browser.
FINANCIALS
FINANCIALS FA, FIN, GP, HP, RV
The filed statements
Income statement, balance sheet and cash flow, several years side by side, with the margins beneath. Every figure carries the file it came from.
COMPARE
COMPARE CMP, CMPR
Two securities, one axis
Opens the comparison view. Type COMPARE A B or CMP A B, or select a security and name a peer.
NEWS
NEWS CN, NEWS, REG
Headlines and the regulatory wire
Press headlines, the regulatory wire and corporate actions in one panel.
ANNOUNCEMENTS
ANNOUNCEMENTS
Company announcements
Announcements published by the listed companies and the exchanges.
BND
BND
Bonds
The bond board for the selected market.
FX
FX
Cross rates and converter
The cross rate matrix and a converter, so a figure quoted in one currency can be read in another.
MACRO
MACRO
Inflation by country
Annual consumer price inflation per market, with the series named and its publication date stated rather than implied.
PORTFOLIO
PORTFOLIO TFOLIO, PF
The book, valued
Positions, market value, cost, profit and loss, exposure by sector and by exchange, and risk per position.
RATINGS
RATINGS
Panel
Opens the RATINGS panel.
REG
REG
Panel
Opens the REG panel.
CORP
CORP
Panel
Opens the CORP panel.
GLCO
GLCO
Panel
Opens the GLCO panel.
TAS
TAS
Panel
Opens the TAS panel.

Workspace

COMPARE A B
COMPARE
Side by side comparison of two securities
Also accepts CMP A B, CMPR A B, or the form A VS B. Opens the compare panel with both securities rebased to a common window.
TILE
TILE
Lay the open panels out side by side
Rearranges the workspace so the open panel windows tile instead of overlapping.
CLOSE <PANEL>
CLOSE
Close one panel window
Closes the named panel, for example CLOSE FINANCIALS. Keeps the centre stage clear for the next command.
RESET
RESET
Clear the workspace back to the default layout
Closes the panel windows and returns the centre stage, useful between demonstrations.
Every figure shown in the terminal is drawn from a published source and names it. Where a figure is unavailable the panel says so rather than showing a zero.
